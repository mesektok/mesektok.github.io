## 은퇴 후 새로운 취미를 찾다

저는 30년간 대학에서 경영학을 가르쳤습니다. 은퇴 후 할 일을 찾다가 우연히 n8n이라는 노코드 자동화 플랫폼을 만났고, 그것이 제 삶을 완전히 바꿨습니다. 특히 Notion에서 관리하던 개인 연구 자료들을 Claude AI로 자동 분석하게 된 후, 더 이상 손으로 일일이 정리할 필요가 없어졌습니다.

오늘 제가 공유할 내용은 제가 직접 만들고 반복적으로 개선해온 워크플로우입니다. Notion 데이터베이스에 저장된 논문 제목과 요약본을 매일 자동으로 Claude AI가 분석하고, 핵심 내용을 다시 Notion에 저장하는 시스템입니다.

## 왜 이 조합이 강력한가

Notion은 훌륭한 데이터 저장소입니다. 하지만 저장된 데이터를 분석하려면 직접 읽고 정리해야 한다는 약점이 있습니다. Claude AI는 뛰어난 분석 능력이 있지만, 자동으로 작동하지는 않습니다. 그리고 n8n은 이 둘을 연결하는 다리 역할을 합니다.

제가 이 워크플로우를 만든 이유는 간단했습니다. 매주 30개 정도의 논문을 Notion에 저장하는데, 각 논문의 핵심을 요약하고 분류하는 데 일주일에 5시간이 걸렸습니다. 은퇴 후 시간이 많다고 해서 반복 작업에 낭비할 이유는 없다고 생각했습니다.

## 구체적인 구현 방법

먼저 Notion에서 데이터베이스를 구성했습니다. 필수 필드는 다섯 개입니다. 제목(Title), 요약본(Summary), 저자(Author), 추가 분석 필요(To Analyze - 체크박스), 그리고 AI 분석 결과(Analysis Result - 롱텍스트). 체크박스 필드가 핵심입니다. 새 논문을 추가할 때 이 상자에만 체크하면 자동으로 워크플로우가 시작됩니다.

n8n에서는 'Notion Trigger'로 시작합니다. 설정은 다음과 같습니다. 데이터베이스를 선택하고, 필터 조건을 "To Analyze equals true"로 설정합니다. 그러면 매분 Notion을 확인해서 새로 체크된 항목을 감지합니다.

두 번째 단계는 데이터 정제입니다. 저는 Set 노드를 사용해서 필요한 정보만 추출합니다. 제목, 요약본, 저자 정보를 별도 변수로 저장하는 방식입니다. 이 단계를 건너뛰는 사람들이 많은데, 나중에 Claude에게 전달할 프롬프트가 복잡해질수록 이 단계의 중요성이 드러납니다.

세 번째가 핵심입니다. Claude AI 노드 설정입니다. n8n은 Anthropic API 통합을 지원합니다. 모델은 Claude 3.5 Sonnet을 선택했습니다. 가격과 성능 면에서 가장 효율적이거든요. 프롬프트는 제가 여러 번 시행착오를 거쳐 만들었습니다. 

"다음 학술 논문을 분석하세요. 제목: {{$node["Set"].data.title}}, 요약: {{$node["Set"].data.summary}}. 이 논문의 핵심 기여, 연구 방법론, 결론을 각각 2-3문장씩 정리하고, 이 논문이 어느 분야(경제학/사회학/심리학/기타)에 가장 관련이 있는지 명시하세요." 

이렇게 구체적인 프롬프트를 쓸수록 결과의 일관성이 높습니다. 처음에는 "이 논문을 분석하세요"라고만 적었는데, 결과 형식이 제각각이어서 다시 정리해야 했습니다.

네 번째 단계는 결과를 Notion에 다시 저장하는 것입니다. 'Update Database Item' 노드를 사용합니다. 페이지 ID(맨 앞의 trigger에서 자동으로 받음)를 지정하고, Analysis Result 필드에 Claude의 응답을 저장합니다. 동시에 To Analyze 체크박스를 해제해서 같은 항목이 다시 처리되지 않도록 합니다.

마지막으로 저는 에러 핸들링을 추가했습니다. Claude API가 응답하지 않거나 Notion이 일시적으로 접근 불가할 수 있으니까요. Error Handling 설정에서 Retry를 3회까지 설정하고, 완전히 실패하면 Slack으로 알림을 받도록 했습니다.

## 실제 운영 경험담

이 워크플로우를 6개월 운영한 경험을 말씀드립니다. 첫 달에는 프롬프트 튜닝으로 바빴습니다. Claude의 응답이 가끔 너무 길거나, 제가 원하는 형식이 아닐 때가 있었거든요. 예를 들어 "핵심 기여"가 무엇인지 명확히 정의하지 않으면, 어떤 결과는 방법론을 핵심으로, 어떤 결과는 발견을 핵심으로 표시했습니다.

50번 정도 워크플로우를 돌린 후에야 지금의 프롬프트에 안정화됐습니다. 요점은 Claude가 완벽하다는 게 아니라, 사람이 충분히 구체적으로 지시해야 한다는 것입니다.

두 가지 추가 개선사항을 소개합니다. 첫째, n8n의 Schedule 기능으로 주 1회 정리 리포트를 만들었습니다. 한 주 동안 분석된 모든 논문을 주제별로 그룹화해서 Notion에 정리 페이지를 만드는 워크플로우입니다.

둘째, 저는 API 비용을 추적하는 별도 로깅을 추가했습니다. 매번 Claude API를 호출할 때마다 토큰 사용량을 기록합니다. 처음엔 월 50달러 정도 예상했는데, 실제로는 월 15달러 선입니다.

## 당신도 시작할 수 있습니다

이 시스템의 가장 좋은 점은 확장성입니다. 저는 이제 이 기본 워크플로우를 바탕으로 다양한 변형을 만들었습니다. 책 리뷰 자동 정리, 개인 일기에서 통찰력 추출, 이메일 받은편지함 자동 분류 등 말입니다.

n8n은 무료 버전도 충분합니다. 자신의 프로세스를 먼저 Notion에 정리하고, n8n의 튜토리얼로 기본을 배운 후, 이 글의 방식을 참고해 시작하길 권합니다. 제가 겪은 시행착오 대부분을 피할 수 있을 것입니다.

지금이라도 당신의 Notion 데이터베이스를 살펴보세요. 반복적으로 분석하거나 정리하는 작업이 있다면, 그것이 바로 자동화의 대상입니다. 저는 은퇴 후 이 기술들 덕분에 더 의미 있는 일에 시간을 쓸 수 있게 됐습니다.
