## "연결이요? 또 영어 화면이잖아요…"

지난 편에서 API 키를 발급받으셨죠?

메모장 어딘가에 `AIzaSy...`로 시작하는 긴 문자열이 저장되어 있을 겁니다.
그게 있으면 오늘 할 일의 절반은 이미 끝난 겁니다.

이번 편은 더 짧습니다.

그 키를 n8n에 붙여넣는 것, 딱 그것만 합니다.
클릭 횟수로 치면 열 번 안에 끝납니다.

---

## 1. 오늘 할 일을 먼저 그림으로 보세요

복잡하게 생각하지 마세요.
오늘 하는 일은 이겁니다.

```
[메모장 속 API 키] → [복사] → [n8n 붙여넣기] → [테스트 클릭] → 완료
```

자동차로 치면 — 열쇠를 만들었으니(지난 편), 오늘은 시동을 거는 겁니다.

---

## 2. 준비물 확인

---

### ✅ 첫째, 지난 편에서 저장한 API 키

메모장을 열어서 `AIzaSy...`로 시작하는 문자열을 확인하세요.
없다면 → [지난 편으로 돌아가서 다시 발급받으세요](#)
5분이면 됩니다. 걱정 마세요.

---

### ✅ 둘째, n8n이 실행 중이어야 합니다

브라우저 주소창에 아래를 입력해서 n8n 화면이 뜨는지 확인하세요.

```
http://localhost:5678
```

화면이 뜨면 준비 완료입니다.
화면이 안 뜨면 → n8n을 먼저 실행하세요. (Docker Desktop → n8n 컨테이너 시작)

---

### ✅ 셋째, 새 워크플로우 하나

기존 워크플로우를 건드리지 않아도 됩니다.
테스트용 빈 워크플로우를 새로 하나 만들어서 진행합니다.
잘못돼도 기존 자동화에 영향 없습니다. 안심하세요.

---

## 3. 단계별 따라하기 — 같이 해봅시다

---

### STEP 1. n8n에서 새 워크플로우 열기

n8n 화면 오른쪽 상단의 **"+ New Workflow"** 버튼을 클릭합니다.

빈 캔버스가 열립니다. 여기서 시작합니다.

> 📸 *[화면 캡처 — New Workflow 버튼 위치]*

---

### STEP 2. 노드 추가 — Google Gemini Chat Model 찾기

캔버스 가운데 **"+"** 버튼을 클릭합니다.
검색창이 뜨면 아래를 입력하세요.

```
Gemini
```

목록에서 **"Google Gemini Chat Model"** 을 찾아 클릭합니다.

> 📸 *[화면 캡처 — Gemini 노드 검색 화면]*

> 💡 **"Google Gemini Chat Model"이 안 보이면?**
> n8n 버전이 낮을 수 있습니다.
> 검색창에 **"Google AI"** 로도 찾아보세요.

---

### STEP 3. Credential 설정 창 열기

노드를 클릭하면 오른쪽에 설정 패널이 열립니다.

**"Credential"** 항목을 찾으세요.
드롭다운 옆에 **"Create new credential"** 또는 **"+ Add"** 버튼이 보입니다.
그걸 클릭합니다.

> 📸 *[화면 캡처 — Credential 설정 패널]*

---

### STEP 4. API 키 붙여넣기 — 핵심입니다

새 창이 열립니다.

**"API Key"** 라고 적힌 입력칸이 보입니다.
거기에 메모장에서 복사한 키를 붙여넣으세요.

```
Ctrl+V
```

그게 전부입니다.

> 📸 *[화면 캡처 — API Key 입력칸]*

입력칸 아래 **"Save"** 버튼을 클릭합니다.

> ⚠️ **주의**
> 키 앞뒤로 빈칸(공백)이 들어가면 오류가 납니다.
> 붙여넣은 후 혹시 앞뒤에 공백이 생겼는지 한 번만 확인하세요.

---

### STEP 5. 모델 선택

Credential 저장이 끝나면 설정 패널로 돌아옵니다.

**"Model"** 항목에서 사용할 Gemini 모델을 선택합니다.

| 모델명 | 특징 |
|---|---|
| **gemini-1.5-flash** | 빠르고 무료 티어 사용 가능 ← 처음엔 이걸로 |
| gemini-1.5-pro | 더 똑똑하지만 무료 한도 소진 빠름 |
| gemini-2.0-flash | 최신, 빠름, 무료 티어 지원 |

처음 테스트라면 **gemini-1.5-flash** 를 선택하세요.

> 📸 *[화면 캡처 — Model 선택 드롭다운]*

---

### STEP 6. 연결 테스트 — AI가 실제로 응답하는지 확인

설정이 끝났으면 실제로 작동하는지 확인해봐야겠죠.

노드 설정 패널 하단의 **"Test step"** 버튼을 클릭합니다.

잠시 기다리면 오른쪽에 결과가 나타납니다.

**초록색 체크 표시**가 보이면 → 연결 성공입니다. 🎉
**빨간색 오류 표시**가 보이면 → 아래 문제해결 섹션을 보세요.

> 📸 *[화면 캡처 — 테스트 성공 화면]*

---

## 4. 오류가 났을 때 — 당황하지 마세요

---

### ❌ "API key not valid" 오류

API 키가 잘못 입력된 겁니다.

1. Credential 설정으로 다시 들어가세요
2. 기존 키를 전부 지우세요
3. 메모장에서 다시 복사해서 붙여넣으세요
4. 앞뒤 공백 없는지 확인하세요

---

### ❌ "Could not connect" 오류

인터넷 연결을 확인하세요.
n8n Docker 컨테이너가 실행 중인지 확인하세요.
잠시 후 다시 테스트해보세요.

---

### ❌ 모델 목록이 안 뜰 때

Credential(API 키)이 제대로 저장됐는지 먼저 확인하세요.
저장이 됐는데도 안 뜨면 → n8n 페이지를 새로고침(F5) 후 다시 시도하세요.

---

## 5. 연결 후 딱 하나만 더

테스트까지 성공했다면 — 이제 Gemini가 n8n 안에서 살고 있는 겁니다.

이 노드를 앞으로 모든 자동화 워크플로우에서 꺼내 쓸 수 있습니다.

오늘 만든 Credential은 저장되어 있습니다.
다음번엔 드롭다운에서 골라쓰기만 하면 됩니다. 다시 키 입력할 필요 없습니다.

> **✅ 오늘의 최종 미션**
> 테스트 성공 화면을 캡처해서 저장해두세요.
> 나중에 오류가 났을 때 "이전엔 됐었다"는 증거가 됩니다.
