## 은퇴 후 발견한 자동화의 가치

저는 35년간 대학에서 행정학을 가르친 교수입니다. 은퇴 후 여유 시간이 생겼을 때, 취미로 시작한 블로그와 개인 프로젝트 관리가 생각보다 복잡해지기 시작했습니다. 매일 밤 Notion에 기록한 아이디어 수백 개를 정리하고, 중요한 것들을 골라내는 작업이 몇 시간씩 걸렸던 것입니다.

2년 전 우연히 n8n이라는 오픈소스 자동화 도구를 발견했고, Claude AI의 강력한 언어 모델과 결합하면 이 모든 작업을 자동화할 수 있다는 깨달음을 얻었습니다. 처음에는 기술적으로 어려울 것 같았지만, 단계별로 접근하니 충분히 가능했습니다. 오늘은 제 경험을 바탕으로 이 워크플로우를 구축하는 방법을 공유하겠습니다.

## n8n과 Notion API의 연결 기초

n8n은 시각적 노드 기반의 워크플로우 빌더로, 코딩 없이도 복잡한 자동화를 구성할 수 있습니다. 먼저 Notion API 연결부터 시작해야 합니다. Notion 개발자 포털에서 새 통합을 생성하고, API 키를 발급받은 후 n8n의 Notion 노드에 입력합니다.

저는 처음에 Notion의 데이터 구조를 제대로 이해하지 못해 몇 번 실패했습니다. 하지만 Notion 데이터베이스의 각 페이지가 객체로 취급되며, 속성(Properties)이 필드라는 점을 깨닫자 훨씬 수월해졌습니다. Notion 노드에서 "Get Database Items"를 선택하면, 특정 데이터베이스의 모든 항목을 가져올 수 있습니다. 제 경우 매월 1일 오전 8시에 자동으로 지난 달 기록을 조회하도록 설정했습니다.

## Claude AI를 통한 지능형 분석

Notion에서 데이터를 가져온 후, 이를 Claude AI에 전달하는 단계가 핵심입니다. Claude의 API를 n8n에서 사용하려면, Anthropic에서 API 키를 발급받아 n8n의 HTTP Request 노드를 설정해야 합니다.

제가 가장 유용하게 활용한 프롬프트는 "다음의 아이디어 목록을 읽고, 실현 가능성과 영향력을 기준으로 상위 5개를 추천하고, 각각에 대해 한 문장 요약을 제공해줘"였습니다. Claude는 단순히 데이터를 정렬하는 수준을 넘어, 맥락을 이해하고 의미 있는 분석을 제공합니다. 대학에서 학생 논문을 평가할 때의 직관과 유사한 수준의 분석이 자동으로 이루어지는 것에 놀라웠습니다.

n8n의 "Function" 노드를 활용해 Notion 데이터를 적절한 텍스트 형식으로 변환하는 것도 중요합니다. 저는 자바스크립트를 조금씩 배우면서 데이터를 정렬하고, 불필요한 필드를 제거하고, 읽기 좋은 형식으로 만드는 코드를 작성했습니다.

## 결과물을 Notion으로 되돌리기

Claude의 분석 결과를 다시 Notion으로 저장하는 것이 워크플로우를 완성합니다. "Create Database Item" 노드를 사용해 새로운 페이지를 생성하거나, "Update Database Item" 노드로 기존 항목을 수정할 수 있습니다.

저는 별도의 "월간 분석 결과" 데이터베이스를 만들어, 매월 Claude가 생성한 추천 아이디어들을 자동으로 저장하도록 설정했습니다. 각 항목에는 원본 아이디어 링크, Claude의 분석 의견, 우선순위 태그가 함께 기록됩니다. 이제 매달 첫날 아침에 일어나면, 지난 달을 정리한 보고서 같은 것이 준비되어 있는 셈입니다.

오류 처리도 중요합니다. n8n의 "Error Handling" 기능을 통해 API 요청 실패나 타임아웃이 발생했을 때 이메일 알림을 받도록 설정했습니다. 초반에는 일주일에 한두 번 오류가 발생했지만, 프롬프트를 다듬고 요청 형식을 최적화하면서 이제는 거의 완벽하게 작동합니다.

은퇴 후 기술을 배우는 것이 쉽지는 않았지만, 작은 자동화부터 시작해 점진적으로 복잡한 워크플로우로 나아가는 방식이 가장 효과적이었습니다. 여러분도 자신의 일상 속 반복되는 작업을 찾아보세요. 이 워크플로우는 블로그 관리, 재무 기록, 독서 노트, 프로젝트 추적 등 다양한 분야에 응용할 수 있습니다.
