# AI가 블로그 글을 대신 써준다 — n8n A루틴 만들기

---

## "제가 자는 동안 블로그 글이 생겨 있었습니다"

솔직히 처음엔 믿지 않았습니다.

밤에 자고 일어났더니 — Google Sheets에 글 초안이 한 편 들어와 있었습니다.
제가 쓴 게 아닙니다. AI가 썼습니다. n8n이 시켰습니다.

1편에서 API 키를 만들었고, 2편에서 n8n에 연결했습니다.
오늘은 그 연결을 실제로 **작동하게** 만듭니다.

이걸 저는 **A루틴**이라고 부릅니다.

> A루틴 = AI가 블로그 글 초안을 써서 → Google Sheets에 저장하는 자동화

오늘 이걸 만들고 나면 — 매일 아침 8시, 여러분이 커피 마시는 동안 AI가 글을 씁니다.

---

## 1. A루틴이 하는 일 — 전체 흐름 한눈에

복잡하게 생각하지 마세요.
A루틴은 딱 세 가지 일을 합니다.

```
① 매일 아침 8시 → 자동으로 깨어남  (Schedule Trigger)
        ↓
② Gemini에게 글 주제와 내용을 요청  (Gemini 노드)
        ↓
③ 완성된 글 초안을 Google Sheets에 저장  (Google Sheets 노드)
```

노드 3개짜리 워크플로우입니다.
오늘 이 세 개를 연결하면 끝입니다.

---

## 2. 준비물 확인

---

### ✅ 첫째, 2편에서 만든 Gemini Credential

n8n에 Gemini API 키가 이미 연결되어 있어야 합니다.
2편을 아직 못 하셨다면 → [2편: Gemini API 키를 n8n에 연결하는 법](#)

---

### ✅ 둘째, Google Sheets 파일 하나

글 초안이 저장될 시트입니다.
구글 드라이브에서 새 스프레드시트를 만드세요.

시트 상단 첫 행(1행)에 아래 항목을 입력해두세요.

| A열 | B열 | C열 | D열 |
|---|---|---|---|
| 날짜 | 제목 | 내용 | 상태 |

> 💡 열 이름은 나중에 n8n에서 그대로 가져다 씁니다.
> 오타 없이 정확히 입력하세요.

---

### ✅ 셋째, Google Sheets 연동 (Credential)

n8n에서 Google Sheets를 쓰려면 구글 계정 연동이 필요합니다.
아직 안 하셨다면 → n8n 설정 → Credentials → Google Sheets OAuth2 추가
(처음 한 번만 하면 이후엔 계속 씁니다)

---

## 3. 워크플로우 만들기 — 노드 3개 연결

---

### STEP 1. 새 워크플로우 열기

n8n 화면 오른쪽 상단 **"+ New Workflow"** 클릭.
빈 캔버스가 열립니다.

워크플로우 이름을 지어주세요.

```
A루틴_블로그글자동생성
```

> 📸 *[화면 캡처 — 빈 캔버스 + 이름 입력]*

---

### STEP 2. 첫 번째 노드 — Schedule Trigger (자동 실행 타이머)

**"+"** 버튼 클릭 → 검색창에 입력:

```
Schedule
```

**"Schedule Trigger"** 를 선택합니다.

설정 패널에서 아래처럼 입력하세요.

| 항목 | 입력값 |
|---|---|
| Trigger Interval | Days |
| Hour | 8 |
| Minute | 0 |

> 매일 아침 8시에 자동으로 워크플로우가 시작됩니다.

> 📸 *[화면 캡처 — Schedule Trigger 설정]*

---

### STEP 3. 두 번째 노드 — Gemini (글 쓰는 AI)

Schedule Trigger 노드 오른쪽 **"+"** 버튼 클릭 → 검색창에 입력:

```
Gemini
```

**"Google Gemini Chat Model"** 선택.

설정 패널에서:

- **Credential** → 2편에서 만든 Gemini 키 선택
- **Model** → `gemini-1.5-flash`

그 다음 **"Messages"** 항목에 아래 프롬프트를 입력합니다.

---

**📝 프롬프트 (그대로 복사해서 붙여넣으세요)**

```
당신은 한국의 시니어 독자를 위한 블로그 작가입니다.

오늘 날짜: {{$now.format('YYYY-MM-DD')}}

아래 조건에 맞는 블로그 글 초안을 작성해주세요.

[조건]
- 주제: 은퇴 후 디지털 도구 활용법
- 분량: 500자 내외
- 톤: 따뜻하고 쉬운 말투, 어려운 용어 없이
- 형식: 제목 1줄 + 본문

반드시 아래 형식으로만 답하세요.
제목: (제목 내용)
본문: (본문 내용)
```

> 📸 *[화면 캡처 — Gemini 노드 프롬프트 입력]*

> 💡 **주제는 바꿔도 됩니다**
> "은퇴 후 디지털 도구 활용법" 대신 여러분 블로그 주제로 교체하세요.
> artontv.kr이라면 → "국내 전시회 및 문화 예술 소식"으로 바꾸면 됩니다.

---

### STEP 4. 세 번째 노드 — Google Sheets (저장소)

Gemini 노드 오른쪽 **"+"** 버튼 클릭 → 검색창에 입력:

```
Google Sheets
```

**"Google Sheets"** → **"Append Row"** 선택.

설정 패널에서:

| 항목 | 입력값 |
|---|---|
| Credential | 구글 계정 연동 선택 |
| Spreadsheet | 준비물에서 만든 시트 선택 |
| Sheet | Sheet1 (기본값) |

그 다음 **"Columns"** 항목에서 아래처럼 연결합니다.

| 열 이름 | 값 |
|---|---|
| 날짜 | `{{$now.format('YYYY-MM-DD')}}` |
| 제목 | `{{$json.message.content[0].text.split('본문:')[0].replace('제목:','').trim()}}` |
| 내용 | `{{$json.message.content[0].text.split('본문:')[1].trim()}}` |
| 상태 | `대기중` |

> 📸 *[화면 캡처 — Google Sheets 노드 설정]*

> ⚠️ **"대기중" 상태값이 중요합니다**
> 나중에 B루틴(발행 자동화)이 이 값을 보고
> 아직 발행 안 된 글만 골라서 블로그에 올립니다.

---

### STEP 5. 세 노드 연결 확인

캔버스를 보면 이렇게 연결되어 있어야 합니다.

```
[Schedule Trigger] → [Gemini] → [Google Sheets]
```

연결선이 끊어진 곳이 없는지 확인하세요.

> 📸 *[화면 캡처 — 전체 워크플로우 연결 화면]*

---

### STEP 6. 테스트 실행

오른쪽 상단 **"Test Workflow"** 버튼을 클릭합니다.

잠시 기다리면 — 각 노드에 초록 체크가 표시됩니다.

Google Sheets를 열어보세요.
2행에 오늘 날짜, AI가 쓴 제목, 본문, "대기중"이 들어와 있으면 성공입니다. 🎉

> 📸 *[화면 캡처 — Google Sheets에 데이터 입력된 화면]*

---

## 4. 오류가 났을 때

---

### ❌ Gemini 노드에서 오류

2편으로 돌아가서 Credential(API 키) 연결이 정상인지 확인하세요.
모델명이 제대로 선택됐는지 확인하세요.

---

### ❌ Google Sheets에 데이터가 안 들어올 때

- 시트 1행의 열 이름(날짜, 제목, 내용, 상태)이 정확한지 확인
- Spreadsheet 선택이 올바른지 확인
- 구글 계정 Credential이 연결됐는지 확인

---

### ❌ 제목·본문이 한 칸에 몰려 들어올 때

Gemini가 프롬프트 형식을 무시하고 자유롭게 답한 겁니다.
프롬프트 마지막 줄을 이렇게 강조해보세요.

```
반드시 아래 형식 외에 다른 말은 쓰지 마세요.
제목: (제목만)
본문: (본문만)
```

---

## 5. 워크플로우 저장 및 활성화

테스트까지 성공했으면 마지막 두 가지만 하면 됩니다.

---

### 저장

오른쪽 상단 **"Save"** 버튼 클릭.

---

### 활성화

오른쪽 상단 토글 스위치를 **켜짐(Active)** 으로 변경합니다.

```
● Active
```

이 스위치가 켜져 있어야 매일 아침 8시에 자동으로 실행됩니다.
꺼두면 수동으로만 실행됩니다.

> 📸 *[화면 캡처 — Active 토글 스위치]*

---

## 마무리 — 이제 AI가 일합니다

오늘 한 일을 정리하면 이겁니다.

- Schedule Trigger로 매일 8시 자동 실행 설정했고 ✅
- Gemini에게 블로그 글 쓰는 명령을 내렸고 ✅
- 결과물이 Google Sheets에 자동 저장됩니다 ✅

내일 아침 커피 한 잔 마시면서 Google Sheets를 열어보세요.
글 초안이 하나 들어와 있을 겁니다.

67세에 처음 이걸 봤을 때 — 솔직히 소름이 돋았습니다.

---

**그런데 글이 Sheets에 쌓이기만 하면 아직 반입니다.**

다음 편은 이 글을 실제 블로그에 자동으로 올리는 **B루틴**입니다.
Sheets에 쌓인 글을 꺼내서 → 블로그에 발행하고 → 상태를 "발행완료"로 바꾸는 것까지.

그게 되면 — 진짜 자동화가 완성됩니다.

---
