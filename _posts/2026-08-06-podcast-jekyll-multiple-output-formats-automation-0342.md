### 🎙️ 오늘의 팟캐스트
Jekyll로 한 페이지에서 HTML과 PDF를 동시에 생성하는 방법

&nbsp;

### 📌 에피소드 주요 내용
- Jekyll에서 하나의 포스트로 여러 파일 형식(HTML, PDF, iCal)을 동시에 생성하는 방법
- 커스텀 플러그인과 GitHub Actions를 활용한 자동화 솔루션
- 수동 작업의 제거로 데이터 일관성 문제 해결

### 🎧 전체 대본
**지혜:** 안녕하세요, 팟캐스트 '기술과 경험' 진행자 지혜입니다. 오늘은 특별한 손님을 모셨는데요, 은퇴 후 블로그를 통해 강의 노트를 공유하고 계신 노교수님입니다. 교수님, 안녕하세요!

**박교수:** 안녕하세요. 반갑습니다. 은퇴 후 새로운 도전을 시작하게 되었는데, 생각보다 기술적인 문제들을 마주하게 되었네요. GitHub Pages와 Jekyll로 블로그를 시작했는데, 구독자들로부터 예상 밖의 요청들이 들어오기 시작했습니다. PDF 형식이나 캘린더 파일 같은 것들 말입니다.

**지혜:** 아, 그렇군요! 사람들이 콘텐츠를 다양한 방식으로 받고 싶어 하는군요. 그럼 처음엔 어떻게 대응하셨어요?

**박교수:** 초반에는 각각의 요청마다 파일을 수동으로 만들고 관리했습니다. 그러나 포스팅을 수정할 때마다 모든 형식의 파일을 다시 업데이트해야 했습니다. 마치 강의 노트를 여러 번 필기하는 악순환이었죠. 이 문제를 해결하기 위해 GitHub의 Jekyll 이슈를 뒤졌고, 결국 두 가지 방법을 찾아냈습니다.

**지혜:** 오! 두 가지 방법이요? 그게 뭔가요?

**박교수:** 첫 번째는 Jekyll 플러그인을 만드는 것입니다. 포스트의 Front Matter에 원하는 출력 형식을 지정하면, 커스텀 플러그인이 Pandoc 같은 도구를 이용해 자동으로 HTML, PDF 등 여러 형식으로 변환해줍니다. 두 번째는 GitHub Actions를 활용한 자동화인데, 로컬 환경에 의존성을 설치할 필요 없이 클라우드에서 모든 변환 작업을 처리합니다.

**지혜:** 와, 그럼 지금은 훨씬 편해지셨겠네요!

**박교수:** 정말 그렇습니다. 이제 저는 포스트를 작성하고 Front Matter에 원하는 형식만 명시하면 됩니다. 나머지는 모두 자동화됩니다. 흥미롭게도 이것은 전 세계 Jekyll 사용자들이 모두 공감하는 문제였고, 커뮤니티에서 이미 많은 해결책들을 공유하고 있었습니다.

**지혜:** 정말 좋은 경험이셨네요. 교수님처럼 비슷한 문제를 겪는 분들도 많을 것 같은데요. 더 자세한 내용은 블로그 원문에서 확인하실 수 있어요. 오늘 귀한 시간 내주셔서 감사합니다!

**박교수:** 감사합니다.
