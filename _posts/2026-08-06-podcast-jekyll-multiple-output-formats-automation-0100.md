### 🎙️ 오늘의 팟캐스트
Jekyll로 한 페이지에서 HTML과 PDF를 동시에 생성하는 방법

&nbsp;

### 📌 에피소드 주요 내용
- Jekyll에서 하나의 포스트로 HTML, PDF, iCal 등 여러 형식의 파일을 동시에 자동 생성하는 플러그인과 GitHub Actions 활용법
- 포스트 수정 시 원본 마크다운 하나만 변경하면 모든 출력 형식이 자동으로 업데이트되는 효율적인 워크플로우 구축
- Jekyll 커뮤니티의 협력으로 문제를 해결하고 솔루션을 오픈소스로 공개하는 개발자 문화의 중요성

### 🎧 전체 대본
**지혜:** 안녕하세요, 여러분! 오늘은 노교수님을 모셨어요. 교수님께서 은퇴 후 Jekyll로 블로그를 운영하시면서 겪으신 흥미로운 경험담을 준비하셨다고 해요. 교수님, 안녕하세요!

**박교수:** 안녕하세요, 지혜. 반갑습니다. 제가 은퇴 후 경제학 강의 노트들을 온라인에 공유하기 위해 GitHub Pages와 Jekyll을 활용하기 시작했는데, 예상 밖의 문제에 직면하게 되었거든요. 구독자들이 같은 포스트를 HTML로는 읽고 싶지만, 또 다른 사람은 PDF로 다운로드 받거나 인쇄해 가고 싶어 하는 거였습니다.

**지혜:** 아, 그런 요청들이 들어왔군요! 처음엔 어떻게 대응하셨어요?

**박교수:** 처음엔 매우 비효율적이었습니다. 각 형식마다 파일을 수동으로 생성하고 관리했거든요. 하지만 포스팅을 수정할 때마다 HTML, PDF, iCal 등 모든 형식을 일일이 업데이트해야 하니, 마치 강의 노트를 여러 번 필기하는 것 같은 중복 작업이었어요. 게다가 어느 파일이 최신 버전인지 헷갈리는 일까지 생겼습니다.

**지혜:** 정말 복잡했을 것 같은데, 그 문제를 어떻게 해결하셨어요?

**박교수:** GitHub의 Jekyll 이슈 페이지를 살펴보니, 전 세계 개발자들이 같은 고민을 하고 있었더군요. 결국 두 가지 방법을 조합했습니다. 첫 번째는 Ruby 플러그인을 만들어서, 포스트의 설정에 원하는 출력 형식을 지정하면 자동으로 여러 파일이 생성되도록 한 거고요. 두 번째는 GitHub Actions를 활용해 빌드 자동화를 설정했습니다. 이제는 원본 마크다운 파일 하나만 수정하면, 모든 형식이 자동으로 업데이트됩니다.

**지혜:** 오, 정말 효율적이네요! 교수님의 해결책이 다른 사람들에게도 도움이 될 것 같은데, 계획이 있으신가요?

**박교수:** 물론입니다. 좋은 해결책은 나누어야 한다고 생각합니다. 저도 이제 이 솔루션을 오픈소스로 공개할 준비를 하고 있어요. Jekyll 사용자 커뮤니티와 함께 이런 경험들을 공유하는 것이 중요하다고 봅니다. 단순함이 Jekyll의 장점이지만, 실제 요구사항을 충족시키려면 창의력과 협력이 필수이거든요.

**지혜:** 정말 멋진 생각이에요! 혹시 Jekyll로 블로그를 운영하시는 분들 중에 같은 고민을 하시는 분들이 계신가요?

**박교수:** 당연하지요. 제가 겪은 문제는 혼자만의 것이 아니었습니다. GitHub의 이슈 페이지에도 많은 개발자들이 같은 기능을 요청했고, 이미 일부 플러그인들이 공개되어 있습니다. 커뮤니티의 협력 덕분에 저도 해결책을 찾을 수 있었던 거죠.

**지혜:** 오늘 정말 유익한 이야기 감사합니다, 교수님! 더 자세한 내용과 구체적인 구현 방법은 블로그 원문에서 확인하실 수 있어요. 여러분도 한 번 읽어보시길 추천드립니다!
