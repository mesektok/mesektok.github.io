### 🎙️ 오늘의 팟캐스트
Jekyll 블로그에서 한 글을 여러 형식으로 출력하는 방법

&nbsp;

### 📌 에피소드 주요 내용
- Jekyll에서 하나의 마크다운 파일로 여러 형식(HTML, iCal, JSON 등)을 동시에 출력하기
- 플러그인 활용, 레이아웃 조건부 렌더링, 빌드 후 스크립트 변환 등 실전 기법 3가지
- 정적 사이트 생성기의 한계를 창의적으로 극복하면 유지보수 효율성을 크게 향상시킬 수 있음

### 🎧 전체 대본
**지혜:** 안녕하세요, 팟캐스트 '코딩이야기'입니다. 오늘은 웹 개발의 실전 사례를 들려주실 노교수님과 함께합니다. 교수님, 대학원 홈페이지 프로젝트에서 재미있는 과제를 만나셨다고요?

**박교수:** 네, 그렇습니다. 모교의 학술 네트워크 프로젝트에 참여하면서 예상치 못한 문제가 발생했어요. 학과 세미나 일정을 웹사이트에 공지했는데, 학생들이 요청한 게 흥미로웠습니다. 일부는 HTML 페이지만으로 충분했지만, 상당수는 스마트폰 달력 앱에 자동으로 입력되는 iCal 파일을 원했던 거죠. 처음엔 동일한 내용으로 각각 따로 만들면 되겠거니 했는데, Jekyll의 기본 구조상 하나의 마크다운 파일은 보통 하나의 형식만 생성한다는 한계에 직면했습니다.

**지혜:** 아, 그래서 고민이 많으셨겠네요. 그럼 어떤 식으로 해결하셨어요?

**박교수:** 여러 방법을 시도했습니다. 첫째, Jekyll 플러그인을 활용하는 것인데, 프론트매터에 출력 형식을 명시하면 자동으로 HTML과 iCal 파일을 동시에 생성하게 만들었어요. 둘째는 레이아웃 내에서 조건부 렌더링을 하는 방식이고, 셋째는 빌드 후 스크립트로 추가 형식을 생성하는 방법입니다. 가장 실용적인 것은 Python이나 Node.js로 생성된 HTML을 파싱해서 iCal로 변환하는 방식이었습니다.

**지혜:** 와, 생각보다 창의적인 해결 방법들이 많네요. 그럼 실제로 적용해보니 어땠어요?

**박교수:** 매우 만족스러웠습니다. 학생들의 반응이 긍정적이었을 뿐만 아니라, 한 번의 포스팅으로 웹페이지와 달력 앱이 동시에 업데이트되니 유지보수 부담도 크게 줄었거든요. 이 경험을 통해 깨달은 것은, 정적 사이트 생성기의 한계를 미리 인식하고 창의적으로 우회하는 것이 얼마나 중요한지라는 점입니다. Jekyll은 완벽하지 않지만, 약간의 노력으로 복잡한 요구사항을 충족시킬 수 있는 유연성이 있습니다.

**지혜:** 정말 좋은 교훈이네요. 혹시 비슷한 문제를 고민 중인 청취자분들을 위해 한 말씀 더 부탁드릴 수 있을까요?

**박교수:** 당연합니다. 만약 Jekyll 블로그에서 여러 형식의 출력이 필요하다면, 자신의 상황에 맞는 세 가지 방법 중 하나를 선택해 적용해보시길 권장합니다. 각각 장단점이 있으니까요.

**지혜:** 좋은 조언 감사합니다, 교수님! 더 자세한 내용과 구체적인 코드 예시는 블로그 원문에서 확인하실 수 있어요. 오늘 함께해주셔서 감사합니다!
