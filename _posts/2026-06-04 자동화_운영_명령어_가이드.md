# 네이버 자동화 운영 명령어 가이드
> blog.naver.com/ganatoday | 계정: emmao1004@naver.com

---

## ① PC 재부팅 후 정상 시작 절차

```
1. Docker Desktop 자동 시작 확인
   → 작업표시줄 고래 아이콘 초록색 확인

2. n8n 자동 시작 확인
   브라우저 → http://localhost:5678
   → 로그인 화면 보이면 ✅

3. Flask 서버 자동 시작 확인
   브라우저 → http://localhost:5001/health
   → {"status": "ok"} 보이면 ✅

4. 모두 정상이면 자동화 작동 중
```

```

확인:
```

## ④ 자동화 중단 시 (포스팅 실패)

### 원인 확인
```
n8n → Workflow C → Executions 탭
→ 실패 항목 클릭
→ 빨간 노드 확인
```

### 서버 확인
```
브라우저 → http://localhost:5001/health
→ {"status": "ok"} ← 정상
→ 연결 안됨       ← 서버 재시작 필요
```

## 전체 자동화 흐름 요약

```
PC 켜기
    ↓
Docker Desktop 자동시작
    ↓
n8n 자동시작 (restart: always)
    ↓
Flask 서버 자동시작 (작업 스케줄러)
    ↓
n8n Workflow C 스케줄 실행
    ↓
콘텐츠 생성 (Claude API)
    ↓
Unsplash 이미지 3장
    ↓
Flask(5001) → naver_worker.py
    ↓
blog.naver.com/ganatoday 자동 포스팅 ✅
카테고리: 세이노지혜
```

---

*문제 발생 시 순서: ① 서버확인 → ② 쿠키갱신 → ③ 테스트실행*
