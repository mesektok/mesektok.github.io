## 서론: 은퇴 후 만난 자동화의 매력

저는 30년간 대학에서 경영학을 가르쳤습니다. 은퇴 후 취미로 개인 프로젝트를 진행하면서 방대한 자료들을 정리하는 일의 번거로움을 깨달았습니다. 매일 50개 이상의 웹 기사와 연구 자료를 Notion에 저장하지만, 이를 체계적으로 분류하는 데만 하루 1시간 이상이 소요되었습니다. 

그러다 우연히 n8n이라는 자동화 도구를 발견했고, Claude AI의 자연어 처리 능력과 Notion API를 결합하면 이 문제를 완전히 해결할 수 있다는 깨달음을 얻었습니다. 오늘 제가 개발한 워크플로우를 여러분과 나누고자 합니다.

## n8n 워크플로우의 기본 구조 설계

n8n은 노드 기반의 자동화 플랫폼으로, 마치 레고 블록을 조립하듯 다양한 서비스를 연결할 수 있습니다. 제가 구축한 워크플로우의 핵심은 세 가지 단계로 이루어져 있습니다.

첫 번째는 **Notion 트리거 설정**입니다. Notion 데이터베이스에 새로운 항목이 추가될 때마다 자동으로 워크플로우가 실행되도록 설정했습니다. 이를 위해 n8n의 Notion 노드를 사용하여 "데이터베이스 아이템 생성됨" 이벤트를 모니터링합니다. 저의 경우, 제목(Title), 내용(Content), 출처(Source) 세 개의 필드를 추적하도록 구성했습니다.

두 번째는 **Claude AI를 통한 지능형 분류**입니다. 새로운 아이템이 감지되면 n8n은 즉시 해당 데이터를 Claude API로 전송합니다. 저는 Claude에게 "이 텍스트를 다음 카테고리 중 하나로 분류하세요: 경영관리, 마케팅, 기술혁신, 인문학, 기타"라는 프롬프트를 작성했습니다. Claude는 컨텍스트를 이해하고 가장 적절한 카테고리를 반환합니다.

세 번째는 **Notion 데이터베이스 업데이트**입니다. Claude의 응답을 받으면 n8n은 자동으로 해당 항목의 "카테고리(Category)" 필드와 "AI 요약(AI Summary)" 필드를 업데이트합니다. 이 과정은 단 몇 초 안에 완료됩니다.

## 실제 구현 과정과 마주한 도전들

이 워크플로우를 구축하면서 여러 기술적 장애물을 만났습니다. 가장 첫 번째 문제는 **API 인증 설정**이었습니다. Notion API와 Claude API 모두 고유한 토큰을 필요로 하는데, n8n의 자격증명(Credentials) 섹션에서 이를 올바르게 등록하는 것이 생각보다 까다로웠습니다. 

Notion의 경우, 통합(Integration)을 생성한 후 "Internal Integration Token"을 복사하여 n8n에 입력해야 합니다. Anthropic의 Claude API의 경우, API 키를 얻기 위해 별도로 크레딧을 충전해야 한다는 점도 처음에는 혼동스러웠습니다. 하지만 Anthropic 콘솔에서 API 키를 생성한 후 n8n의 HTTP Request 노드에 커스텀 헤더로 추가하니 문제가 해결되었습니다.

두 번째 도전은 **프롬프트 엔지니어링**이었습니다. 초반에 Claude에게 너무 모호한 지시를 내리면 부정확한 분류 결과를 얻었습니다. 저는 수십 번의 테스트를 거쳐 다음과 같은 구조화된 프롬프트를 완성했습니다: "당신은 전문 정보 분류가입니다. 다음 텍스트를 읽고 JSON 형식으로 응답하세요: {category: '선택된 카테고리', confidence: 0~1 사이의 신뢰도, summary: '50자 이내 요약'}". 이렇게 하니 Claude의 응답을 프로그래매틱하게 처리하기가 훨씬 수월해졌습니다.

## 나의 성과와 앞으로의 개선 방향

이 워크플로우를 3개월간 운영한 결과, 놀라운 변화를 경험했습니다. 매일 50개의 자료를 수동으로 분류하던 1시간이 완전히 단축되었습니다. 더욱 중요한 것은, Claude AI의 분류 정확도가 약 94% 수준으로 매우 높다는 점입니다. 오분류된 항목을 바로 수정하더라도 일 5분 정도만 소요됩니다.

현재 저는 이 워크플로우에 추가 기능들을 고려 중입니다. 예를 들어, 자동으로 생성된 요약을 기반으로 중복 자료를 감지하거나, 특정 카테고리의 자료가 쌓이면 자동으로 주간 리포트를 생성하는 기능입니다. 또한 Claude의 비용 최적화를 위해, 매우 짧은 텍스트의 경우 Claude 대신 더 저렴한 GPT 모델을 사용하는 조건부 로직도 추가할 예정입니다.

은퇴 후 이런 자동화 기술을 배우면서 느낀 점은, 나이와 기술 습득은 무관하다는 것입니다. 정보화 시대에는 자동화의 가치를 이해하고 작은 단계부터 시작하는 것이 무엇보다 중요합니다. 여러분도 지금 바로 n8n 무료 계정을 만들어 간단한 워크플로우부터 시험해보시기를 강력히 권장합니다.
