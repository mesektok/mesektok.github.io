서울대학교에서 30년간 경제학을 가르쳤던 나는 은퇴 후 본격적으로 학문 정리 블로그를 시작했습니다. 그런데 예상치 못한 문제가 생겼습니다. HTML 형식의 블로그 포스팅은 잘 작동하는데, 같은 포스트 내용으로 학술 일정을 iCal 형식(.ics)으로도 동시에 만들어야 한다는 요청이 들어왔거든요. 마치 한 종류의 원고를 여러 출판사 형식에 맞춰 내야 하는 것처럼요.

## Jekyll의 한계를 마주치다

처음엔 문제가 간단할 줄 알았습니다. Jekyll은 정적 사이트 생성기이니 기본 설정만 조정하면 될 거라고 생각했죠. 하지만 GitHub의 공식 이슈 추적소(#3041)를 살펴보니 많은 사용자들이 동일한 어려움을 겪고 있었습니다. 

기본적으로 Jekyll은 하나의 마크다운 파일에서 하나의 출력 형식(보통 HTML)만 생성하도록 설계되었습니다. 예를 들어 `2026-07-26-my-lecture.md` 파일은 항상 `my-lecture/index.html`로만 변환됩니다. 내가 필요했던 것은 같은 콘텐츠에서 HTML 페이지와 iCal 파일을 동시에 만드는 것이었는데, 이는 기본 기능으로는 불가능했습니다.

내 경우, 매주 금요일 특강 정보를 포스팅할 때마다 학생들의 캘린더에 자동으로 추가되길 원했습니다. 현대 대학생들은 구글 캘린더나 아웃룩 같은 디지털 캘린더를 당연하게 여기기 때문입니다. 하지만 Jekyll 기본 설정으로는 이것이 불가능했던 거죠.

## 레이아웃 플러그인으로 돌파구를 찾다

해결책은 생각보다 우아했습니다. Jekyll의 강력한 플러그인 시스템과 커스텀 레이아웃을 활용하는 것이었습니다. 내가 찾은 방법은 크게 두 가지였습니다.

첫 번째는 `jekyll-multiple-outputs`라는 커뮤니티 플러그인을 사용하는 것입니다. 이 플러그인은 하나의 마크다운 파일에서 여러 개의 출력 파일을 생성할 수 있도록 해줍니다. 프론트매터(YAML 헤더)에 `outputs: [html, ics]` 같은 형식으로 지정하면, Jekyll이 자동으로 HTML과 iCal 파일을 동시에 생성합니다.

두 번째 방법은 더 세심한 제어가 필요할 때 사용하는 방식입니다. `_plugins` 디렉토리에 루비 스크립트를 작성하여 post-processing 훅을 추가하는 것입니다. 각 포스트가 생성될 때마다 추가 파일을 만들 수 있도록 하는 방식이죠. 나는 다음과 같은 구조로 구현했습니다:

```ruby
Jekyll::Hooks.register :posts, :post_write do |post|
  # HTML 생성 후 iCal 파일 동시 생성
  ical_content = generate_ical_from_post(post)
  File.write(post.destination_dir + '/calendar.ics', ical_content)
end
```

이렇게 하면 각 포스트 폴더 내에 `index.html` 뿐만 아니라 `calendar.ics` 파일도 함께 생성됩니다. 학생들은 이 링크를 클릭하면 자신의 캘린더 애플리케이션으로 행사를 바로 추가할 수 있게 되었습니다.

## 실제 적용과 시행착오

처음 시도할 때는 여러 번 실패했습니다. 프론트매터 문법이 잘못되었거나, 레이아웃 파일 경로를 잘못 설정했거든요. 특히 한국어 타이틀이 인코딩되면서 깨지는 문제도 있었습니다. 하지만 GitHub의 Jekyll 커뮤니티 토론을 읽으면서 해결책을 하나씩 찾을 수 있었습니다.

지금은 매주 새로운 특강 정보를 포스팅할 때마다 HTML 페이지와 iCal 파일이 자동으로 함께 생성됩니다. 학생들은 예전처럼 이메일을 통해 링크를 받고, 클릭 한 번이면 자신의 캘린더에 행사가 추가되는 경험을 합니다.

더 놀라운 점은 이 방식이 확장 가능하다는 것입니다. 이제 PDF 생성, JSON 형식의 데이터 제공, RSS 피드 커스터마이징 등 다양한 출력 형식을 동일한 논리로 추가할 수 있습니다. 한 번의 포스팅이 여러 채널로 자동 배포되는 셈입니다.

제 경험이 여러분의 블로그 운영에도 도움이 되었기를 바랍니다. 혹시 유사한 상황을 겪고 계신다면, 깃허브 Jekyll 저장소의 이슈 #3041과 관련 플러그인들을 꼭 확인해 보세요.
