## 은퇴 후 발견한 작은 자동화의 기적

작년 대학을 떠나던 날, 저는 30년간 모아온 학생 피드백 데이터 2,000개를 어떻게 정리할지 한숨이 나왔습니다. 손으로 분류하기엔 너무 많고, 비용을 들여 용역을 맡기기도 영 맘에 걸렸죠. 그러던 중 n8n, Claude AI, Notion이라는 세 도구를 만났고, 이들을 연결하는 방법을 배우면서 제 인생이 조금 바뀌었습니다.

며칠 전 외동딸이 저를 찾아와선 "아빠, 이게 정말 자동화로 됐어?" 하며 놀라워했습니다. 대량의 데이터가 분류되고 인사이트가 추출되는 모습이 마법처럼 보였던 것 같습니다. 오늘은 제 경험을 바탕으로 Notion과 Claude를 n8n으로 엮는 실전 방법을 공유하겠습니다.

## n8n 워크플로우 기본 설정: 첫 걸음을 내딛다

n8n은 노드 기반의 자동화 플랫폼입니다. 처음엔 복잡해 보이지만, 교실에서 학생들을 가르치던 경험으로 보면 이렇게 생각할 수 있습니다. 각 노드(Node)는 특정 작업을 하는 조교라고 생각하면 됩니다. 조교들을 줄 세우고 업무를 분배하면 전체 프로세스가 자동으로 흘러가는 겁니다.

먼저 n8n 계정을 만들고 새로운 워크플로우를 시작합니다. 저는 "Notion 데이터 분석" 이라는 이름으로 시작했습니다. 첫 번째 노드는 **Notion 데이터베이스 조회**입니다. Notion API 토큰을 발급받아 연결하면, Notion에 저장된 모든 데이터에 접근할 수 있습니다. 저의 경우 학생 피드백이 저장된 테이블에 연결했습니다.

두 번째 단계에서 조심해야 할 점이 있습니다. Notion에서 데이터를 가져올 때 각 항목(Item)을 반복 처리해야 한다는 것입니다. n8n의 "Loop" 기능을 사용하여 데이터베이스의 각 행을 하나씩 처리하도록 설정했습니다. 처음엔 이 부분이 낯설었지만, 몇 번 실패해보니 금방 이해가 갔습니다.

## Claude AI 통합: 데이터에 지능을 더하다

여기서 진짜 마법이 일어납니다. Claude AI는 단순한 텍스트 처리가 아니라, 맥락을 이해하고 의미 있는 분석을 수행합니다. n8n에서 Claude 노드를 추가할 때, API 키를 설정하고 프롬프트를 작성해야 합니다.

저는 다음과 같은 프롬프트를 작성했습니다: "다음 학생 피드백을 읽고 세 가지를 해주세요. 첫째, 감정 톤을 긍정/중립/부정으로 분류하세요. 둘째, 피드백의 핵심 주제를 한 문장으로 요약하세요. 셋째, 개선 가능한 구체적인 행동 항목을 제시하세요." 

Claude는 이 지시사항을 완벽하게 따릅니다. 마치 제가 예전에 논문을 지도할 때처럼, AI가 학생 피드백 하나하나에 대해 깊이 있는 피드백을 주는 것 같았습니다. 데이터 2,000개를 수동으로 분석했다면 몇 달이 걸렸을 작업이, 몇 시간 안에 끝났습니다.

중요한 팁 하나: Claude의 응답을 구조화된 형식으로 받으려면, 프롬프트에서 JSON 포맷을 명시적으로 요청하세요. 이렇게 하면 나중에 데이터를 다시 처리할 때 훨씬 수월합니다.

## Notion으로 결과 저장: 자동화의 완성

마지막 단계는 Claude의 분석 결과를 다시 Notion으로 돌려보내는 것입니다. 이를 위해 "Notion 데이터베이스 업데이트" 노드를 사용합니다. 저는 Notion 테이블에 네 개의 새로운 칼럼을 추가했습니다: 감정톤, 주제 요약, 개선사항, 처리날짜.

이 부분에서 제가 처음 실수한 것은 Notion의 데이터베이스 ID와 프로퍼티 ID를 정확히 파악하지 못한 것입니다. 하지만 Notion API 문서를 차근차근 읽고, 작은 테스트 데이터베이스로 연습하니 금방 해결됐습니다. 교수 생활 중 새로운 교과서를 배울 때처럼 말입니다.

워크플로우를 저장하고 처음 실행했을 때의 감정은 정말 특별했습니다. 몇 초 안에 첫 번째 피드백이 분석되고, 결과가 Notion에 자동으로 저장되는 모습을 보며, 제가 기술과 너무 멀리 살아온 게 아닌가 하는 생각이 들었습니다.

## 실전에서 배운 교훈들

30년 교육 경험과 3개월간의 자동화 실험을 통해 몇 가지 배운 점이 있습니다. 첫째, 작은 것부터 시작하세요. 저도 처음엔 50개 데이터로 시작해서 천천히 확대했습니다. 둘째, 에러 처리를 미리 생각하세요. n8n의 "Error Handler" 기능으로 문제가 발생했을 때의 대응책을 마련해두면 정말 도움이 됩니다. 셋째, 정기적으로 워크플로우를 검토하세요. 데이터나 요구사항이 바뀌면 프롬프트도 조정해야 합니다.

비용도 합리적입니다. n8n 무료 플랜으로도 충분히 시작할 수 있고, Claude API는 사용량에 따라 지불하기 때문에 대량 처리가 아니면 부담 없습니다. 저는 월 5,000원 정도로 2,000개 데이터를 분석하고 있습니다.

혹시 여러분도 쌓여있는 데이터를 어떻게 처리할지 고민하고 계신가요? 더 이상 기술은 어려운 사람들만의 영역이 아닙니다. 이 가이드를 따라 직접 워크플로우를 만들어보고, 여러분의 데이터를 지능형으로 자동 분석해보세요. 댓글로 여러분의 자동화 경험담도 나눠주시면 정말 감사하겠습니다.
