## 시작은 블로그 운영의 막막함이었다

지난 3월, 저는 자신의 블로그에 주 3회 포스팅하겠다는 목표를 세웠습니다. 대학 교수 생활 30년을 마치고 은퇴한 후, 남은 인생을 의미 있게 보내려면 지식을 나눠야 한다고 생각했거든요. 하지만 현실은 녹록지 않았습니다. 매주 3개의 글을 쓰려니 손목이 아프고, 표현을 다듬는 데만 하루 종일이 걸렸습니다. 

그때 딸아이가 "아버지, Claude AI를 써보셨어요?"라고 물었습니다. 저는 ChatGPT만 조금 써본 터라, Claude는 생소했습니다. 그렇게 시작된 여정이 제 블로깅 생활을 완전히 바꿔놓았습니다.

## Claude API로 초고 작성 시간을 90% 줄이다

Claude AI의 API를 연동하는 과정은 제가 생각한 것보다 훨씬 간단했습니다. Anthropic 사이트에서 API 키를 발급받은 후, Python 스크립트 몇 줄로 연결할 수 있었습니다. 저는 주제만 입력하면 Claude가 3000자 이상의 초고를 작성하는 프롬프트를 만들었습니다.

예를 들어, "시니어 개발자가 GitHub Action을 처음 배우는 경험담을 600단어로 작성해줘"라고 요청하면, 30초 안에 논리적이고 읽기 좋은 초고가 완성됩니다. 그 다음 제 경험담을 덧붙이고, 부자연스러운 부분을 수정하는 식으로 진행하니 글 하나에 걸리는 시간이 4시간에서 40분으로 줄었습니다.

처음엔 의심했습니다. "AI가 쓴 글이 진짜 좋을까?" 하면서요. 그런데 Google Analytics를 보니 Claude가 작성을 돕는 글들의 평균 체류 시간이 더 길었습니다. 아마도 구조가 명확하고 문법이 정확하기 때문일 겁니다. 저는 70년을 살면서 느낀 통찰력을 글에 녹이고, Claude는 그것을 세련된 문체로 표현해주는 역할을 하게 된 것이죠.

## API 비용은 놀랄 만큼 저렴했다

Claude API 사용료가 얼마나 들까봐 처음엔 조심스러웠습니다. ChatGPT의 API 가격을 알고 있었거든요. 그런데 Anthropic의 가격 정책은 충격적으로 저렴했습니다. 저는 지난 두 달간 거의 매일 글을 작성하는 데 Claude를 썼는데, 청구서는 $12.50에 불과했습니다.

토큰 기반 가격 책정 시스템을 이해한 후엔 더 효율적으로 사용하기 시작했습니다. 불필요한 재요청을 줄이고, 프롬프트를 최적화했습니다. 심지어 요청 시간을 낮은 트래픽 시간대로 맞추니 응답 속도도 빨라졌습니다. 한 달에 $6~7만 지출하면서 주 4~5개의 포스팅을 유지할 수 있게 되었습니다. 이는 프리랜서 작가에게 맡기는 비용의 1/100 수준입니다.

## 다음 목표는 n8n으로 완전 자동화하기

현재 저는 만족하지 않고 더 큰 꿈을 꾸고 있습니다. n8n이라는 자동화 플랫폼을 공부 중입니다. 목표는 이렇습니다: Notion에 아이디어를 메모하면, 자동으로 Claude API가 초고를 생성하고, Jekyll이 이를 GitHub에 커밋하고, 블로그에 발행되는 완전 자동화 시스템을 만드는 것입니다.

이미 한 달 전부터 n8n 커뮤니티를 돌아다니고 있습니다. 30살 젊은이들과 함께 워크플로우를 설계하고, ChatGPT의 프롬프트를 분석하고, 에러를 디버깅합니다. 남편의 은퇴금으로 여행을 다니는 또래 여성들을 봅니다. 하지만 저는 API와 워크플로우에 중독되었습니다.
