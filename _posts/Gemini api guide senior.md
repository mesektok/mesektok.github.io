## "API 키요? 그거 해커들이 쓰는 거 아닌가요?"

솔직히 말씀드리겠습니다.

저도 처음 'API 키'라는 단어를 봤을 때 손이 멈췄습니다. 화면에는 영어가 가득하고, 뭔가 누르면 요금이 청구될 것 같고, 잘못 건드렸다가 컴퓨터가 망가질 것 같은 느낌.

67세에 처음 혼자 블로그 자동화를 시작한 저도 그랬으니까요.

그런데 막상 해보니까 — **딱 5분이었습니다.**

구글 계정만 있으면 됩니다. 카드 번호 안 씁니다. 코딩도 없습니다. 그냥 버튼 몇 번 누르면 `AIza...`로 시작하는 문자열 하나가 생깁니다. 그게 전부입니다.

이 글은 그 5분을 함께 걷는 안내서입니다.

---

## 1. API 키가 뭔지 딱 한 줄로

**API 키 = 도서관 출입증**

도서관에 들어가려면 회원증이 있어야 하죠.

Gemini(구글의 AI)도 마찬가지입니다. 아무나 마음대로 쓰면 서버가 버티질 못하니까, 구글은 "당신이 누구인지 확인된 사람"에게만 출입증을 발급해 줍니다. 그게 바로 **API 키**입니다.

이 출입증을 n8n이나 내 블로그 자동화 프로그램에 꽂아두면 — 프로그램이 알아서 구글 AI에게 "저 박 교수님 대신 왔습니다"라고 신분증을 내밀어 줍니다.

그러면 AI가 글을 써줍니다.

그게 전부입니다.

> **딱 하나만 기억하세요**
> API 키 = 나만의 출입증. 만들기는 쉽고, 잃어버리면 안 됩니다.

---

## 2. 시작 전 준비물 확인 — 안심하세요

**딱 세 가지만 확인하세요.**

---

### ✅ 첫째, 구글 계정

지메일(Gmail) 쓰고 계시죠? 그거면 됩니다.
유튜브 로그인할 때 쓰는 그 계정 그대로 씁니다.
새로 만들 필요 없습니다.

---

### ✅ 둘째, 돈은 안 냅니다

구글은 무료 티어를 제공합니다.
개인 블로그 자동화 수준에서는 무료로 충분합니다.
카드 번호 입력 화면 나오지 않습니다. 그냥 진행하세요.

> 나중에 사용량이 크게 늘면 그때 가서 결정해도 됩니다.
> 지금은 그냥 만들기만 합니다.

---

### ✅ 셋째, 영어가 나와도 괜찮습니다

화면이 영어로 되어 있습니다. 당황하지 마세요.
누를 버튼은 딱 두 개입니다.

- **Get API key** → API 키 받기
- **Create API key** → API 키 만들기

이 두 문장만 알면 끝입니다.
나머지 영어는 그냥 지나쳐도 됩니다.

---

## 3. 단계별 따라하기 — 저랑 같이 해보세요

---

### STEP 1. Google AI Studio 접속

아래 주소를 클릭하거나, 구글 검색창에 **"Google AI Studio"** 라고 치세요.

👉 [https://aistudio.google.com](https://aistudio.google.com)

페이지가 열리면 구글 계정으로 로그인합니다.
평소 유튜브 볼 때 쓰는 그 계정 그대로요.

> 📸 *[화면 캡처 — 로그인 화면 삽입]*

---

### STEP 2. 약관 동의 화면

처음 접속하면 영어로 된 동의 화면이 나올 수 있습니다.
겁먹지 마세요. 그냥 **"I agree"** 또는 **"Continue"** 버튼을 누르면 됩니다.

> 💡 이 화면이 안 나오는 분도 있습니다. 그러면 바로 STEP 3으로 가세요.

> 📸 *[화면 캡처 — 약관 동의 화면 삽입]*

---

### STEP 3. "Get API key" 클릭

로그인이 되면 왼쪽에 메뉴가 보입니다.
거기서 **"Get API key"** 를 찾아 클릭합니다.

화면 왼쪽 상단, 열쇠 모양 아이콘 옆에 있습니다.

> 📸 *[화면 캡처 — Get API key 메뉴 위치 삽입]*

---

### STEP 4. "Create API key" 버튼 클릭

파란 버튼이 보입니다. **"Create API key"** 를 누르세요.

누르면 작은 창이 뜨면서 선택지가 두 개 나옵니다.

- **Create API key in new project** ← 이걸 누르세요
- Create API key in existing project ← 지금은 무시

처음 하시는 분은 무조건 위에 걸 선택하면 됩니다.

> 📸 *[화면 캡처 — Create API key 버튼 삽입]*

---

### STEP 5. 키 복사 — 여기가 핵심입니다

잠깐 기다리면 이런 문자열이 나타납니다.

```
AIzaSy...........Xk9mQ
```

이게 바로 나만의 API 키입니다.

오른쪽의 **복사(Copy) 버튼**을 누른 뒤 — 메모장을 열고 붙여넣기(`Ctrl+V`) 하세요.
그리고 저장해 두세요. 끝입니다.

> 📸 *[화면 캡처 — API 키 복사 화면 삽입]*

> ⚠️ **이 창을 그냥 닫아도 됩니다.**
> 나중에 같은 메뉴에서 다시 확인할 수 있습니다.

## 4. 발급 후 딱 하나만 하세요

**키를 받았습니다. 이제 뭘 해야 할까요?**

아무것도 안 해도 됩니다. 지금은요.

---

인터넷을 찾아보면 이런 말들이 쏟아집니다.

- "Python SDK에 적용하세요"
- "환경 변수로 관리하세요"
- "REST API 엔드포인트에 연결하세요"

전부 맞는 말입니다. 그런데 지금 당장은 몰라도 됩니다.

오늘 할 일은 딱 하나입니다.

---

> **✅ 오늘의 미션**
> 발급받은 API 키를 메모장에 붙여넣고 저장한다.
> 파일 이름: **gemini-api-key.txt**
> 저장 위치: 내 문서 폴더 안

그게 전부입니다.

---

이 키는 다음 편에서 n8n에 꽂아 넣을 겁니다.
그때 꺼내서 복사하면 됩니다.

지금은 잃어버리지만 않으면 됩니다.

> 💡 **혹시 키를 잃어버렸다면?**
> Google AI Studio에 다시 접속해서 같은 메뉴를 열면 됩니다.
> 새로 하나 더 만들 수도 있습니다. 걱정 마세요.

## 5. 보안 주의사항 — 통장 비밀번호라고 생각하세요

**딱 하나만 지켜주세요.**

---

API 키는 강력합니다.

이 문자열 하나로 구글 AI를 마음대로 쓸 수 있습니다.
그 말은 — 다른 사람이 이 키를 가져가면, 그 사람도 **내 계정으로** AI를 마음대로 쓸 수 있다는 뜻입니다.

요금이 발생할 수도 있습니다. 내 명의로요.

---

### ❌ 하지 말아야 할 것

- 카카오톡 단톡방에 공유하기
- 블로그 글에 키를 그대로 복사해서 올리기
- 유튜브 영상 화면에 키가 보이게 녹화하기
- 이메일로 누군가에게 보내기

---

### ✅ 해야 할 것

- 메모장에 저장 후 파일은 내 컴퓨터 안에만 보관
- 다른 사람이 쓰는 컴퓨터에는 저장하지 않기
- 키가 노출됐다고 의심되면 즉시 삭제하고 새로 발급

> 💡 **키를 삭제하는 방법**
> Google AI Studio → Get API key 메뉴 → 키 옆 휴지통 아이콘 클릭
> 10초면 됩니다. 언제든 새로 만들 수 있으니 겁내지 마세요.

---

그 외의 보안 설정은 지금 단계에서 몰라도 됩니다.
지금은 **"통장 비밀번호처럼 혼자만 보관"** 이것 하나면 충분합니다.
