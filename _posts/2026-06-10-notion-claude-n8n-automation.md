## 은퇴 후 만난 자동화의 매력

지난해 대학을 떠난 후, 저는 마침내 책장에 먼지 쌓인 블로그를 다시 꺼내게 되었습니다. 30년간 강의실에서 데이터를 다루며 살아온 터라, 정보 관리에 대한 강박증이 사라지지 않았거든요. Notion에 강의 노트, 읽은 논문, 그리고 각종 메모를 저장하고 있는데, 점점 늘어나는 데이터를 손으로 일일이 분석하기는 버거워졌습니다. 바로 그때 발견한 것이 n8n과 Claude AI의 조합이었습니다.

처음에는 프로그래밍 경험이 전혀 없어 걱정했지만, n8n의 직관적인 인터페이스와 Claude AI의 강력한 텍스트 처리 능력이 만나니 마치 매직이 일어나는 듯했습니다. 몇 주간의 시행착오 끝에, 제 Notion 데이터베이스를 자동으로 정리하고 분석하는 워크플로우를 완성했습니다. 오늘 그 경험을 여러분과 나누고자 합니다.

## n8n 워크플로우의 기본 구조 설계

n8n은 No-Code 자동화 플랫폼으로, 마치 블록을 조립하듯 워크플로우를 만들 수 있습니다. Notion API와 Claude AI를 연결하는 기본 흐름은 다음과 같습니다. 먼저 Notion 데이터베이스에서 데이터를 불러오는 트리거 노드를 설정합니다. 이는 매일 정해진 시간에 실행되도록 스케줄링할 수 있으며, 특정 조건을 만족하는 항목만 필터링하는 것도 가능합니다.

저의 경우, 매주 월요일 아침 8시마다 지난주에 추가된 모든 메모를 자동으로 수집하도록 설정했습니다. Notion API 연결 시 필요한 API 토큰은 Notion 개발자 콘솔에서 쉽게 발급받을 수 있으며, n8n의 자격증명 관리 시스템이 이를 안전하게 저장해줍니다. 이 부분에서 가장 많은 초보자가 실수하는데, API 토큰의 유효 범위를 정확히 설정하는 것이 중요합니다.

데이터를 불러온 후에는 필터 노드를 추가하여 필요한 정보만 선별합니다. 저는 '분석필요' 태그가 붙은 항목들만 다음 단계로 넘기도록 설정했는데, 이렇게 하면 불필요한 API 호출을 줄여 비용을 절감할 수 있습니다. 마지막으로 함수 노드를 사용해 데이터를 Claude AI가 이해할 수 있는 형식으로 변환합니다.

## Claude AI를 활용한 지능형 데이터 분석

Claude AI를 n8n과 연결하는 것은 생각보다 간단합니다. Anthropic에서 제공하는 API 키를 발급받으면, n8n의 HTTP Request 노드를 통해 직접 Claude를 호출할 수 있습니다. 더 편리한 방법은 n8n의 공식 Claude 통합을 사용하는 것인데, 이미 인증과 매개변수가 미리 설정되어 있어 초보자도 쉽게 사용할 수 있습니다.

저는 Claude에게 다음과 같은 작업을 맡겼습니다. 첫째, 길고 지저분한 메모를 핵심만 뽑아 정리하기. 둘째, 메모의 주제를 자동으로 분류하기. 셋째, 중요도를 평가해 별점 매기기입니다. Claude의 프롬프트를 설계할 때는 구체성이 매우 중요합니다. '메모를 정리해줘'라고 하면 결과가 일관성 없지만, '다음 메모에서 핵심 개념 3가지, 적용 가능한 방법론 2가지, 추가 학습 자료 1개를 JSON 형식으로 추출해줘'라고 하면 완벽한 구조화된 결과를 얻습니다.

지난 3개월간 Claude AI가 처리한 메모는 약 300개였고, 정확도는 95% 이상이었습니다. 가끔 개념적 오류가 발생했을 때는 프롬프트를 미세 조정하여 다시 실행했는데, 이 과정 자체가 데이터에 대해 깊이 있게 생각하게 해주었습니다.

## 결과를 Notion으로 자동 역입하기

Claude AI의 분석 결과를 다시 Notion에 저장하는 것으로 워크플로우를 완성합니다. n8n의 Notion 업데이트 노드를 사용하면, JSON 형식의 분석 결과를 Notion의 데이터베이스 속성에 매핑할 수 있습니다. 저는 원본 메모와 별도의 '분석 결과' 데이터베이스를 만들었으며, 양쪽에 관계 속성으로 링크를 연결했습니다.

이렇게 하면 한눈에 모든 메모의 상태를 파악할 수 있습니다. 대시보드 뷰에서 별점 4점 이상만 필터링하면 중요 자료가 모두 드러나고, 주제별로 그룹화하면 관련 아이디어들이 한곳에 모입니다. 특히 유용한 기능은 오류 처리입니다. 워크플로우가 실패하면 특정 채널로 알림을 보내도록 설정했으며, 실패한 항목들은 별도의 '재처리 큐'로 이동시켰습니다.

지난 3개월 동안 이 워크플로우 덕분에 매주 약 8시간을 절약했습니다. 그 시간을 다시 읽기, 논문 쓰기, 그리고 새로운 공부에 투자할 수 있었으니 너무도 소중한 시간이었습니다.
