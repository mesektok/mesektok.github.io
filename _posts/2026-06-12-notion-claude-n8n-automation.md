## 은퇴 후 발견한 세 가지 기술의 조화

저는 35년간 대학에서 정보시스템학을 가르치다가 작년에 은퇴했습니다. 교수 생활을 마치며 수십 년 쌓인 강의 노트, 논문, 학생 평가 데이터를 어떻게 정리할지 고민하던 중 우연히 n8n이라는 자동화 플랫폼을 발견했습니다. 처음엔 "이렇게 복잡한 도구가 필요할까" 싶었지만, Notion에 저장된 수천 개의 데이터를 Claude AI로 분석하려니 자동화가 필수였습니다.

이번 글은 제가 실제로 구축한 워크플로우를 바탕으로, Notion 데이터베이스의 정보를 자동으로 읽어 Claude AI로 분석하고 결과를 다시 Notion에 저장하는 방법을 공유합니다.

## n8n 워크플로우 설계의 핵심

n8n은 시각적으로 워크플로우를 구성할 수 있는 오픈소스 자동화 도구입니다. 저는 처음 이 플랫폼을 배울 때, "노드"라는 개념을 이해하는 것이 가장 중요했습니다. 각 노드는 특정 작업을 수행하는 블록이며, 이들을 연결하여 하나의 자동화 파이프라인을 만드는 것입니다.

제 워크플로우의 구조는 다음과 같습니다. 첫째, 매일 아침 8시마다 실행되는 **스케줄 트리거** 노드로 시작합니다. 둘째, Notion API를 통해 특정 데이터베이스에서 처리되지 않은 항목들을 조회합니다. 셋째, 각 항목을 Claude AI에 전송하여 요약, 분류, 감정 분석 등을 수행합니다. 마지막으로 분석 결과를 Notion 데이터베이스의 새로운 칼럼에 기록합니다.

특히 중요한 것은 **에러 핸들링**입니다. 초기에는 API 호출 실패나 토큰 제한으로 자주 작업이 중단됐는데, n8n의 "에러 아웃풋" 연결을 활용하여 실패한 항목을 별도로 기록하고 재시도 로직을 추가했습니다.

## Notion API와 Claude AI의 실무 연동

Notion API를 사용하려면 먼저 Integration을 생성하고 데이터베이스에 액세스 권한을 부여해야 합니다. 저는 여기서 몇 시간을 헤맸는데, 결국 "Internal Integration Token"을 복사하여 n8n 자격증명에 저장하는 것이 핵심이었습니다.

Notion 노드에서는 "Query database" 옵션을 선택하여 필터 조건을 설정합니다. 예를 들어 "상태"가 "미분석"인 항목만 가져오도록 구성했습니다. 데이터 양이 많으면 **페이지네이션** 처리가 필수입니다. 저는 100개씩 배치로 나누어 처리하도록 설정했습니다.

Claude AI 연동은 Anthropic API를 통해 이루어집니다. n8n의 HTTP Request 노드를 사용하여 Claude 엔드포인트로 요청을 보냅니다. 프롬프트는 매우 구체적으로 작성해야 합니다. 저는 "다음 강의 평가를 긍정/중립/부정으로 분류하고, 주요 개선점 3가지를 제시하세요"라는 방식으로 작성했습니다. 토큰 사용량을 고려하여 입력 길이를 제한했고, Claude의 응답을 JSON 형식으로 받도록 구성했습니다.

## 실제 운영 경험과 최적화 팁

지난 6개월간 이 워크플로우를 운영하면서 배운 점들을 공유하겠습니다. 첫째, **API 비용 관리**가 중요합니다. Claude는 토큰 기반 과금이므로, 불필요한 중복 요청이 없도록 Notion에서 이미 분석된 항목을 제외하는 로직을 추가했습니다.

둘째, **응답 시간 최적화**입니다. 초기에는 각 항목을 하나씩 처리했는데, n8n의 배치 처리 기능을 활용하여 여러 항목을 한 번에 처리하도록 변경했습니다. 처리 시간이 70% 단축되었습니다.

셋째, **모니터링과 로깅**입니다. 자동화 시스템은 "셋업하고 잊는" 방식으로는 위험합니다. n8n 대시보드에서 정기적으로 실행 이력을 확인하고, 실패율이 높아지면 즉시 원인을 파악했습니다.

넷째, **프롬프트 엔지니어링**의 중요성입니다. 같은 기능이라도 프롬프트를 정제하니 Claude의 응답 품질이 획기적으로 올랐습니다. 예를 들어 "요약해줘"보다 "한국어로 3문장 이내로 요약"이 훨씬 나았습니다.

또한 Notion 데이터베이스의 타입을 적절히 설정하는 것도 중요했습니다. 분석 결과를 저장할 때 "텍스트"가 아닌 "멀티셀렉트"로 분류를 저장하고, "숫자" 타입으로 신뢰도 점수를 저장했습니다. 이렇게 하니 Notion에서 데이터 필터링과 정렬이 훨씬 효율적이 되었습니다.

## 결론: 자동화가 주는 자유

은퇴 후 이 시스템을 구축하며 느낀 가장 큰 변화는 "인적 오류 제거"입니다. 반복적인 데이터 처리 작업에서 해방되어 더 의미 있는 분석에 시간을 쓸 수 있게 되었습니다. n8n, Notion API, Claude AI의 조합은 처음엔 복잡해 보였지만, 각 도구의 역할을 이해하면 매우 강력한 자동화 시스템을 만들 수 있습니다.
